Bienvenue dans Cube Hub LLM

Le petit cube suit les conversations de ton IA locale : il est bleu quand elle écrit, vert quand la réponse est prête. Il se branche sur Open WebUI, sur ton serveur.

Celle que tu ouvres dans le navigateur, par exemple http://192.168.1.50:3000
Dans Open WebUI : ton profil (en bas à gauche) → Réglages → Compte → Clés API → Créer une clé. Elle commence par « sk- ». Elle est chiffrée sur cet ordinateur.

Le widget est en haut à droite de l'écran (Ctrl+Alt+L pour le cacher), et le petit cube dans la zone de notification. Tout se règle ensuite dans le Hub → Réglages → Serveur.
